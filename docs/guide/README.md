# User guide

Start with [install.md](install.md), then read whatever you need.

| Guide | What it covers |
| --- | --- |
| [install.md](install.md) | Build `wy`, run the hub on a laptop or a server (Docker, systemd, Caddy, Tailscale), add machines |
| [agents.md](agents.md) | Setting Watchyard up with an AI agent: where each step is, and what stays with you |
| [accounts.md](accounts.md) | Account folders, labels, launchers, what the folders share, plans, backups and undo |
| [board.md](board.md) | The board in a browser, on a phone, in a terminal and inside Claude Code; the plugin from GitHub |
| [desktop.md](desktop.md) | The desktop app: claude.ai tabs per account, the usage strip, the Hub view |
| [android.md](android.md) | The Android app: build, sideload, pair by QR, notifications, widgets, battery settings |
| [alerts.md](alerts.md) | What notifies you and where: rules, channels, quiet hours, private notifications |
| [usage.md](usage.md) | Usage limits and analytics, and where the numbers come from |
| [peers.md](peers.md) | Sessions messaging across accounts and machines; the owner key, step by step |
| [claude-ai.md](claude-ai.md) | Privacy, risks and how Watchyard talks to claude.ai: sign-ins, the tabs' user agent, opt-in usage reading |
| [security.md](security.md) | Security and privacy model: what leaves each machine, what the hub stores, threat model |
| [maintenance.md](maintenance.md) | Backups, restore, upgrades, moving the hub |
| [troubleshooting.md](troubleshooting.md) | `wy doctor`, common problems, logs, filing a bug |
| [uninstall.md](uninstall.md) | Removing Watchyard from machines, the hub and your devices |
| [faq.md](faq.md) | Common questions, including terms and privacy |

The behaviour behind every guide is specified in [docs/spec/](../spec/README.md). When a guide
and a spec disagree, the spec is right; please open an issue.
