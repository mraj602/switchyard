## Decisions made in this phase

See the spec files; the main ones:

- Folders: config `~/.config/switchyard/config.toml` (shared with the prototype's Electron
  folder under strict rules), state `~/.local/state/switchyard`, data
  `~/.local/share/switchyard`, the same on macOS; `%LOCALAPPDATA%\Switchyard\…` on Windows
  (paths.md).
- Record ids are ULIDs made by the client; duplicates are by id alone (record.md 3.1).
- The outbox uses an exclusive lock on the day file around one `write()` per record
  (outbox.md 3).
- SessionStart enters `done` ("new"), not `working` (states.md 1).
- `derived.last_message` keeps the last 400 characters, not about 200, so the question
  detector sees options lists (record.md 4.1).
- The device token lives in `<state>/token`, not in `config.toml` (tokens.md 2).
