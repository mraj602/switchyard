Connect Claude Code

Run once per account on this machine. It adds Notification + Stop hooks to that account's settings.json (a backup is kept) so sessions — including Remote Control ones — show up under “Needs you” and as desktop notifications.

Background & sync

Switchyard collects usage only while it runs. Let it start hidden when you log in and keep running when the window is closed, so tracking never stops.

Self-hosted server (optional)

Push usage, limits, Claude Code tokens and alerts to your own Switchyard server (see server/ and docker-compose.yml) to view analytics from any browser or phone. claude.ai sign-ins never leave this computer.
